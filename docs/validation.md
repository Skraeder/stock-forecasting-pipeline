# Validación independiente: pendiente (compañero 1)

El pipeline incluye controles defensivos de formato, integridad de snapshots, precios faltantes/negativos, sesiones y ventanas completas. Esto NO equivale al entregable independiente de validaciones y pruebas.

| Control requerido | Evidencia esperada | Estado |
|---|---|---|
| Columnas y tipos | resultado por tabla | Pendiente |
| Faltantes | porcentajes y justificación por variable | Pendiente |
| Duplicados | conteo por clave y conflictos | Pendiente |
| Rangos | precios, volumen, scores | Pendiente |
| Consistencia temporal | cierres especiales y no fuga | Pendiente |
| Consistencia entre tablas | artículos -> agregados -> modelo | Pendiente |
| Volumen esperado | sesiones calendario y cobertura proveedor | Pendiente |
| Pruebas principales | comando y resultados de tests | Pendiente |

No reemplazar Pendiente con Aprobado sin ejecutar y registrar resultados reales.
